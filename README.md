# Card Hand

a godot addon that lets you create a deck of cards. Used for Card2D node

## Installation

Make sure to download the ChillCube Developer tools: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Using the Godot Plugin
Enable the **ChillCube Tools** plugin, then paste the repo URL into the Clone tab.

### Linux / CLI
```bash
clone-gd-addon https://github.com/ChillCube/Card_Hand.git
```

## Documentation
https://github.com/ChillCube/Card Hand/blob/main/DOCUMENTATION.md

## Deinstallation
Use the CC Tools panel in Godot, or run:
```bash
remove-gd-addon Card Hand
```

## For Developers
```bash
push-all-addons
```

## Dependencies

- [PlacementArea2D](https://github.com/ChillCube/PlacementArea2D)
- [Grid](https://github.com/ChillCube/Godot_Grid)
